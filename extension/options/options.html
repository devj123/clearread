ClearRead: Cognitive Mode

Options

Reading profile

Applies to the reading overlay on any page. This is the same profile the popup, the dock, and every page share, so changing it here changes it everywhere.

AI features (optional)

Off by default. ClearRead's rule is nothing leaves your browser -- these three features are the one exception, and only when you turn this on and supply your own API key. Everything else in Cognitive Mode ("What was I doing?", the working-memory sidebar's default view, mission control, the complexity detector) runs entirely on-device with no network calls, key or no key. See PRIVACY.md in the extension folder for the full accounting of what gets sent, when, and to which provider.

Turning this on enables: Chunk this task, the sidebar's "Enhance with AI" button, and attention-aware summaries.

Stored only in this browser's local extension storage (chrome.storage.local), never synced, never sent anywhere except directly to your chosen provider's API when you use an AI feature.
